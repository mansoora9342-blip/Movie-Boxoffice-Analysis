# Movie Box Office Analysis

## Project Overview
   This project analyzes box office performance data of 100+ movies to identify revenue, profitability, and performance trends using Excel and Power BI.

## Tools & Technologies
  Microsoft Excel
  Power BI

## Project Workflow
   Cleaned and validated movie data in Excel (budget, box office, profit, dates).
   Prepared KPIs such as profit, revenue trends, and performance status
   Built interactive Power BI dashboards to analyze genre-wise revenue, yearly trends, budget vs box office, and TRP impact.

## Key Insights
   Identified high-performing genres and profitable budget ranges.
   Analyzed seasonal and yearly box office trends.
   Evaluated movie performance using profitability and audience metrics.

## Outcome
   This project demonstrates practical data analysis, KPI creation, and dashboard development skills relevant to entry-level Data Analyst roles.
